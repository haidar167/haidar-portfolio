## 🎯 Features

| Feature | Description |
|---------|-------------|
| 🎨 **Modern Dark UI** | Glassmorphism cards, gradient accents, ambient glow effects |
| 🖱️ **Custom Cursor** | Blend-mode cursor with smooth follower animation |
| 📐 **3D Tilt Cards** | Interactive perspective tilt on project/service cards |
| 🧲 **Magnetic Buttons** | Buttons that react to cursor proximity |
| 📜 **Scroll Reveals** | Intersection Observer-powered 3D entrance animations |
| 📊 **Scroll Progress** | Top progress bar tracking page scroll position |
| 📱 **Fully Responsive** | Mobile-first design with adaptive navigation |
| ⚡ **Zero Dependencies** | Pure HTML/CSS/JS — fast load, no build step |

```

├── index.html      # Main HTML — all sections & inline styles
├── style.css       # Additional/override styles
├── main.js         # Animations, cursor, tilt, scroll effects
└── .nojekyll       # Bypasses Jekyll processing on GitHub Pages
```

## 🚀 Getting Started

### Quick Start
```bash
# Clone the repository
git clone https://github.com/haidar167/haidar-portfolio.git

# Navigate into the project
cd haidar-portfolio

# Open in your browser
start index.html        # Windows
# open index.html       # macOS
# xdg-open index.html   # Linux
```

### Local Development Server (Optional)
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .

# Then visit http://localhost:8000
```
